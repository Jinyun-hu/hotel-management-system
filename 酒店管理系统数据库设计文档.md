## 1. 数据库设计概述

### 1.1 设计原则

- 遵循第三范式（3NF），减少数据冗余
- 主键采用自增ID，保证数据唯一性
- 时间字段统一使用 DATETIME 类型
- 状态字段使用 ENUM 或 VARCHAR 存储枚举值

### 1.2 数据库配置建议

```sql
-- 创建数据库
CREATE DATABASE hotel_management 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE hotel_management;
```

## 3. 表结构设计

### 3.1 用户表 (sys_user)

#### 3.1.1 表结构

| 字段名 | 数据类型 | 是否必填 | 默认值 | 说明 |
|--------|----------|----------|--------|------|
| id | INT | 是 | 自增 | 用户ID，主键 |
| username | VARCHAR(50) | 是 | - | 用户名，唯一 |
| password | VARCHAR(255) | 是 | - | 密码（加密存储） |
| name | VARCHAR(100) | 是 | - | 姓名 |
| email | VARCHAR(100) | 是 | - | 邮箱地址 |
| role | VARCHAR(20) | 是 | 'admin' | 角色：admin-管理员 |
| status | TINYINT | 是 | 1 | 状态：0-禁用，1-启用 |
| create_time | DATETIME | 是 | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | 是 | CURRENT_TIMESTAMP | 更新时间 |

#### 3.1.2 建表语句

```sql
CREATE TABLE sys_user (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(255) NOT NULL COMMENT '密码',
    name VARCHAR(100) NOT NULL COMMENT '姓名',
    email VARCHAR(100) NOT NULL COMMENT '邮箱地址',
    role VARCHAR(20) NOT NULL DEFAULT 'admin' COMMENT '角色：admin-管理员',
    status TINYINT NOT NULL DEFAULT 1 COMMENT '状态：0-禁用，1-启用',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

### 3.3 房间表 (room)

#### 3.3.1 表结构

| 字段名 | 数据类型 | 是否必填 | 默认值 | 说明 |

```sql
CREATE TABLE room (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '房间ID',
    room_number VARCHAR(20) NOT NULL COMMENT '房间编号',
    room_type_id INT NOT NULL COMMENT '所属房型ID（逻辑外键）',
    floor INT NOT NULL COMMENT '所在楼层',
    status VARCHAR(20) NOT NULL DEFAULT 'available' COMMENT '房间状态：available-空闲，occupied-已入住，cleaning-清洁中，maintenance-维修中',

    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY uk_room_number (room_number),
    KEY idx_room_type (room_type_id),
    KEY idx_floor (floor),
    KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='房间表';
```

| 字段名 | 数据类型 | 是否必填 | 默认值 | 说明 |

| guest_count | INT | 是 | 1 | 入住人数 |
| room_id | INT | 是 | - | 预订房间ID（逻辑外键） |
| room_type_id | INT | 是 | - | 预订房型ID（逻辑外键） |
| check_in_date | DATE | 是 | - | 入住日期 |
| check_out_date | DATE | 是 | - | 退房日期 |
| nights | INT | 是 | 0 | 入住天数 |
| status | VARCHAR(20) | 是 | 'pending' | 订单状态 |

| total_amount | DECIMAL(10,2) | 是 | - | 订单总金额 |

```sql
CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '订单ID',
    order_no VARCHAR(50) NOT NULL COMMENT '订单编号',
    guest_name VARCHAR(100) NOT NULL COMMENT '客人姓名',
    guest_phone VARCHAR(20) NOT NULL COMMENT '客人电话',
    guest_id_card VARCHAR(20) NOT NULL COMMENT '客人身份证号',
    guest_count INT NOT NULL DEFAULT 1 COMMENT '入住人数',
    room_id INT NOT NULL COMMENT '预订房间ID（逻辑外键）',
    room_type_id INT NOT NULL COMMENT '预订房型ID（逻辑外键）',
    check_in_date DATE NOT NULL COMMENT '入住日期',
    check_out_date DATE NOT NULL COMMENT '退房日期',
    nights INT NOT NULL DEFAULT 0 COMMENT '入住天数',
    status VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT '订单状态：pending-待入住，active-入住中，completed-已完成，canceled-已取消',
    payment_status VARCHAR(20) NOT NULL DEFAULT 'unpaid' COMMENT '支付状态：unpaid-未支付，paid-已支付，refunded-已退款',
    total_amount DECIMAL(10,2) NOT NULL COMMENT '订单总金额',
    remark VARCHAR(500) DEFAULT NULL COMMENT '备注',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE KEY uk_order_no (order_no),
    KEY idx_room_id (room_id),
    KEY idx_room_type_id (room_type_id),
    KEY idx_guest_phone (guest_phone),
    KEY idx_guest_id_card (guest_id_card),
    KEY idx_status (status),
    KEY idx_payment_status (payment_status),
    KEY idx_check_in_date (check_in_date),
    KEY idx_check_out_date (check_out_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='订单表';
```

## 5. 表关系说明

### 5.1 关系概述

| 关系 | 主表 | 从表 | 关系类型 | 说明 |
|------|------|------|----------|------|
| 用户-日志 | sys_user | operation_log | 1:N | 一个用户可产生多条操作日志 |
| 房型-房间 | room_type | room | 1:N | 一种房型可包含多间具体房间 |
| 房型-订单 | room_type | orders | 1:N | 一种房型可有多个订单 |
| 房间-订单 | room | orders | 1:N | 一间房可有多个历史订单 |

### 5.2 逻辑外键说明

> 本设计采用**逻辑外键**策略，数据库层面不强制设置 FOREIGN KEY 约束，而是通过应用层代码实现数据完整性校验。

| 字段 | 关联表 | 应用层校验规则 |
|------|--------|----------------|
| room.room_type_id | room_type | 新增/修改房间时验证房型ID是否存在且状态为active |
| orders.room_id | room | 创建订单时验证房间ID存在且状态为available |
| orders.room_type_id | room_type | 创建订单时验证房型ID存在且状态为active |
| operation_log.user_id | sys_user | 记录日志时验证用户ID存在 |

**保留索引说明**：虽然移除了物理外键约束，但保留了对应的索引以提升关联查询性能。

## 6. 常用查询示例

### 6.1 统计数据

```sql
-- 今日入住数（入住日期为今天的订单数）
SELECT COUNT(*) FROM orders 
WHERE DATE(check_in_date) = CURDATE();

-- 今日实际入住且已支付的订单数
SELECT COUNT(*) FROM orders 
WHERE DATE(check_in_date) = CURDATE() AND status = 'active' AND payment_status = 'paid';

-- 总房间数
SELECT COUNT(*) FROM room;

-- 可用房间数
SELECT COUNT(*) FROM room WHERE status = 'available';

-- 今日订单数（创建的订单数）
SELECT COUNT(*) FROM orders 
WHERE DATE(create_time) = CURDATE();

-- 今日营收（入住日期为今天且已支付的订单总金额）
SELECT COALESCE(SUM(total_amount), 0) FROM orders 
WHERE DATE(check_in_date) = CURDATE() AND payment_status = 'paid';

-- 入住率（避免除零错误）
SELECT CASE 
    WHEN COUNT(*) > 0 THEN ROUND((COUNT(CASE WHEN status = 'occupied' THEN 1 END) / COUNT(*)) * 100, 2)
    ELSE 0 
END as occupancy_rate 
FROM room;
```

### 6.2 房态查询

```sql
-- 查询所有房间及房型信息
SELECT r.id, r.room_number, r.floor, rt.name as room_type_name, 
       r.status, r.clean_status, r.price
FROM room r
LEFT JOIN room_type rt ON r.room_type_id = rt.id
ORDER BY r.floor, r.room_number;

-- 按楼层统计房态
SELECT floor,
       COUNT(*) as total,
       SUM(CASE WHEN status = 'available' THEN 1 ELSE 0 END) as available,
       SUM(CASE WHEN status = 'occupied' THEN 1 ELSE 0 END) as occupied,
       SUM(CASE WHEN status = 'cleaning' THEN 1 ELSE 0 END) as cleaning,
       SUM(CASE WHEN status = 'maintenance' THEN 1 ELSE 0 END) as maintenance
FROM room
GROUP BY floor;
```
